## 👋 About

I'm a **Software Architect and Full-Stack Developer** focused on designing and building enterprise software systems.

My engineering interests increasingly converge around:

**Software Architecture → Distributed Systems → AI Systems → Adaptive Software**

I enjoy working on problems where software engineering goes beyond simply making an application work:
